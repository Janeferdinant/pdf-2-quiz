Human memory is an active, constructive information-processing system encompassing three sequential stages: encoding, storage, and retrieval. Richard Atkinson and Richard Shiffrin proposed the multi-store model of memory, conceptualizing information as passing through sensory memory, short-term memory, and long-term memory.

Sensory memory briefly holds environmental stimuli in raw, unprocessed sensory buffers. Iconic memory holds visual sensory traces for approximately 250 to 500 milliseconds, whereas echoic memory preserves auditory traces for approximately three to four seconds. Information attending to conscious focus transitions into short-term memory (STM).

Short-term memory possesses limited duration and capacity. In 1956, George Miller identified that short-term memory can store roughly seven plus-or-minus two meaningful units of information, a concept termed Miller's Magic Number. More contemporary cognitive research, pioneered by Alan Baddeley, conceptualizes this stage as Working Memory—an active workspace comprising a central executive, a phonological loop for auditory rehearsal, a visuospatial sketchpad for visual imagery, and an episodic buffer for integrating multimodal information. Working memory capacity can be effectively expanded through chunking, the cognitive grouping of isolated bits of data into coherent, higher-order units.

Long-term memory (LTM) has essentially unlimited capacity and can preserve memories for decades. LTM bifurcates into explicit (declarative) and implicit (non-declarative) memory systems. Explicit memory encompasses episodic memory (personally experienced autobiographical events) and semantic memory (factual knowledge and conceptual understanding). Implicit memory encompasses procedural memory (motor skills and habits, such as riding a bicycle) and emotional conditioning.

Forgetting occurs through various mechanisms, notably interference. Proactive interference arises when old information hinders the recall of newly acquired information. Conversely, retroactive interference occurs when new learning disrupts the retrieval of previously stored information.
